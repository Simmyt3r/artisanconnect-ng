# ArtisanConnect NG

A platform connecting artisans and service providers with customers in Nigeria.

## Description

ArtisanConnect helps users find skilled professionals for various services including plumbing, electrical work, carpentry, and more.

Built with PHP.

## Features
- Service provider profiles
- Customer search and booking
- Location-based matching
